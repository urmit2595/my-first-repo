# my-first-repo

## Shuriken Showdown

A small browser fighting/shooting game in a single `index.html` (plain HTML, CSS and JavaScript, nothing to install).
Open `index.html` in a browser and press **Enter** to start.

- Best-of-three rounds, 60-second timer, Easy / Normal / Hard AI
- **A/D** move, **W** jump, **S** guard
- **J** Palm Strike, **K** Throwing Star, **J → K** Spiral Burst combo, **L** Vortex Blast (costs 50 energy)
- **P** pause; on-screen buttons on touch devices
